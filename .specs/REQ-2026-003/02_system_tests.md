# L1 テスト計画(E2E): summarize

方針: 一時ディレクトリに入力と設定ファイルを置き、`python -m src.summarize` を実プロセスで実行する。LLM は、テストが書く偽のスクリプト(受け取ったプロンプトをファイルに追記し、決まった文を標準出力へ返す)に置き換える。

| ID | 入力 | 期待する結果 | 要件 |
|---|---|---|---|
| SUM-E01 | 「第1章」「第2章」を持つテキスト、偽の LLM | `summary.md` に `# 第1章`、要約、`# 第2章`、要約。終了コード 0。標準出力に summary.md のパス | F05、F08 |
| SUM-E02 | 本文 1,000 字の 1 章、`summary_ratio` 0.2、`summary_min_chars` 300 | 記録されたプロンプトに「約 300 字」 | F02 |
| SUM-E03 | `density_rounds` 2 | LLM の呼び出し 3 回。2、3 回目のプロンプトに本文と直前の応答。summary.md は 3 回目の応答 | F03 |
| SUM-E04 | 任意の章 | 1 回目のプロンプトに F04 の各条件の語が入る | F04 |
| SUM-E05 | 同じ入力・設定で 2 回実行 | 2 回目は LLM の呼び出しが増えない。summary.md は同一 | F06 |
| SUM-E06 | 2 回目の実行で `summary_ratio` を変える | LLM が再び呼ばれる | F06 |
| SUM-E07 | プロンプトが `max_prompt_bytes` を超える章 | 終了コード 2。標準エラーに章の題。LLM の呼び出し 0 回。summary.md なし | F07 |
| SUM-E08 | 2 章目で必ず失敗する LLM(`llm_retries` 1) | 終了コード 3。標準エラーに 2 章目の題。summary.md なし。1 章目の保存が残る | F07 |
| SUM-E09 | 3 章のテキストに `--chapters 2` | summary.md は 2 章目だけ | F01 |
| SUM-E10 | 未知のキーを含む設定 | 終了コード 2。キー名が標準エラーに | F08 |
| SUM-E11 | 任意の入力 | 標準エラーの最初の行に、`llm_command` の先頭の語 | F09 |
| SUM-E12 | 出力の summary.md を、偽のエンジンの txt2speech に渡す | 章ごとの MP3 ができる(2 つのコマンドがつながる) | F05 |
| SUM-E14 | 本文 100 字の章、`summary_min_chars` 300 | 記録されたプロンプトに「約 100 字」 | F02 |
| SUM-E15 | 成功済みの summary.md がある状態で、設定を変えて失敗する LLM | 終了コード 3。summary.md は元のまま | F05、F07 |
| SUM-E16 | 要約が `# 見出し` の行を含む | summary.md を txt2speech の章分割に通しても章数が変わらない | F05 |
| SUM-E17 | 1 回目に非常に長い要約、書き直しが上限を超える | 終了コード 2。標準エラーに章の題。呼び出しは 1 回 | F07 |
| SUM-E18 | 子プロセスを起こして眠る LLM、短いタイムアウト | 終了コード 3。子プロセスが残っていない | F07 |
| SUM-E19 | 2 章の入力 | 標準エラーに `要約 1/2`、`要約 2/2` の行 | F08 |
| SUM-E20 | 設定の `chapters` が 1、コマンド行が `--chapters 2` | 2 章目だけ | F08 |
| SUM-E13 | 存在しない入力 | 終了コード 2。ファイル名が標準エラーに | F08 |

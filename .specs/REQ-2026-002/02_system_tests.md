# L1 テスト計画(E2E): txt2speech

方針: 一時ディレクトリに入力を置き、`python -m src.txt2speech` を実プロセスで実行する。VOICEVOX は、テストが起動する偽の HTTP サーバー(`/version`、`/audio_query`、`/synthesis`、`/user_dict_word` に応答し、受け取った要求を記録する)に置き換える。FFmpeg は実物。

| ID | 入力 | 期待する結果 | 要件 |
|---|---|---|---|
| T2S-E01 | 見出し「第1章」「第2章」の UTF-8 のテキスト | `01_第1章.mp3`、`02_第2章.mp3` ができる。終了コード 0。標準出力にファイル名 | F04、F10 |
| T2S-E02 | 見出しのない短いテキスト | 1 つの MP3 ができる。題名は入力ファイルの語幹 | F04 |
| T2S-E03 | Shift_JIS のテキスト | 成功。偽サーバーが受け取った文字列が文字化けしていない | F01 |
| T2S-E04 | ルビ 3 形式を含むテキスト | 偽サーバーが受け取った文字列は読みだけ | F02 |
| T2S-E05 | 偽サーバーなし(接続できない) | 終了コード 3。標準エラーにエンジンの URL。出力先に MP3 も進捗ファイルもない | F06 |
| T2S-E06 | 存在しない入力 | 終了コード 2。ファイル名 | F10 |
| T2S-E07 | 生成した MP3 | ffprobe で、形式 mp3、サンプルレート 44100、モノラル、ビットレート約 128 kbps。ID3 の題名=見出し、アーティスト=`VOICEVOX`、アルバム=入力の語幹、トラック=連番、ジャンル=`Audiobook` | F08 |
| T2S-E08 | `--ffmpeg /nonexistent/ffmpeg` を指定 | 終了コード 3。FFmpeg の不在を示す。偽サーバーは合成の要求を受けていない | F08 |
| T2S-E09 | 1 万文字(偽サーバー、複数章) | エラーなく章ごとの MP3 ができる。偽サーバーが受けた文字列を連結すると、前処理後の本文から改行と前後の空白を除いたものに等しい。同時に処理中の要求は常に 1 件 | F05、F06、受入基準 |
| T2S-E10 | 偽サーバーが 1 回目だけ 503 を返す | 再試行して成功する | F06 |
| T2S-E11 | 存在しない出力先ディレクトリ(親も) | 作られ、MP3 ができる | F08 |
| T2S-E22 | 本文が「第1章でも簡単に触れたが、…。」で始まり、見出しのないテキスト(実データの試用で見つかった誤認) | 1 つの MP3 ができ、題名は入力ファイルの語幹。ファイル名に本文の文は入らない | F04 |
| T2S-E12 | 数字見出し「1.1 概要」「1.2 方法」を含むテキスト | 2 つの章に分かれる | F04 |
| T2S-E13 | 生成した MP3 の統合ラウドネス(ffmpeg の `ebur128`)とトゥルーピーク | -16 LUFS ±1.0、トゥルーピーク -1.0 dBFS 以下(許容 +0.1) | F08 |
| T2S-E14 | `--cover` に jpg を指定 | MP3 に画像のストリームが入る(ffprobe)。指定しなければ入らない | F08 |
| T2S-E15 | 辞書の CSV を指定した設定 | 偽サーバーは `/user_dict_word` を、最初の `/audio_query` より前に、行ごとに受け取る。CSV の誤りは行番号つきで終了コード 2 | F03 |
| T2S-E16 | 長いチャンクに 500 を返す偽サーバー | 半分に分けた文字列で再送され、成功する。分けられない長さまで 500 が続けば終了コード 3 | F06 |
| T2S-E17 | 途中(2 章のうち 1 章を作った後)で止めた実行を、同じ入力と設定で再実行 | 完了した章のチャンクは再び合成されない(偽サーバーの記録)。全章が完了し、`.txt2speech_work` と進捗ファイルは残らない | F09 |
| T2S-E18 | 再開の途中で入力を書き換える | 進捗を捨てて最初から行う | F09 |
| T2S-E19 | `--config` の YAML で話速、ポーズ、ビットレートを変える。引数でも話者を指定 | 偽サーバーの問い合わせに設定の話速が入る。引数が設定ファイルに優先する | F10 |
| T2S-E20 | エンジンの URL が `http://example.com:50021` | 通信せずに終了コード 2。偽サーバーは何も受けない | F11 |
| T2S-E21 | 実行の進捗 | 標準エラーに章の番号とチャンクの進みが出る(`tqdm`)。標準出力はファイル名の一覧だけ | F10 |

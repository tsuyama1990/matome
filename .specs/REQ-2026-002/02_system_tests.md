# L1 テスト計画(E2E): txt2speech

方針: 一時ディレクトリに入力を置き、`python -m src.txt2speech` を実プロセスで実行する。VOICEVOX は、テストが起動する偽の HTTP サーバー(`/audio_query`、`/synthesis` に応答)に置き換える。FFmpeg は実物。

| ID | 入力 | 期待する結果 | 要件 |
|---|---|---|---|
| T2S-E01 | 見出し「第1章」「第2章」の UTF-8 のテキスト | `01_第1章.mp3`、`02_第2章.mp3` ができる。終了コード 0。標準出力にファイル名 | F03、F08 |
| T2S-E02 | 見出しのない短いテキスト | 1 つの MP3 ができる。題名は入力ファイル名の語幹 | F03 |
| T2S-E03 | Shift_JIS のテキスト | 成功。偽サーバーが受け取った文字列が文字化けしていない | F01 |
| T2S-E04 | ルビ 3 形式を含むテキスト | 偽サーバーが受け取った文字列は読みだけ | F02 |
| T2S-E05 | 偽サーバーなし(接続できない) | 終了コード 3。標準エラーにエンジンの URL | F05 |
| T2S-E06 | 存在しない入力 | 終了コード 2。ファイル名 | F08 |
| T2S-E07 | 生成した MP3 | ffprobe で、ID3 の題名=見出し、トラック=連番、形式が MP3 | F07 |
| T2S-E08 | `--ffmpeg /nonexistent/ffmpeg` を指定 | 終了コード 3。FFmpeg の不在を示す | F07 |
| T2S-E11 | 存在しない出力先ディレクトリ(親も) | 作られ、MP3 ができる | F08 |
| T2S-E12 | 数字見出し「1.1 概要」「1.2 方法」を含むテキスト | 2 つの章に分かれる | F03 |
| T2S-E09 | 長い入力(2,000 文字) | すべてのチャンクが偽サーバーに届き、MP3 の長さが 0 より大きい | F04、F06 |
| T2S-E10 | 偽サーバーが 1 回目だけ 503 を返す | 再試行して成功する | F05 |

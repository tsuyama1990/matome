# REQ-2026-002 txt2speech: 教科書テキストの音声化(MVP)

状態: 草案。入力の要求定義書は、3.3.1 の途中(「パラメータ微調整」)で切れている。切れた後の 3.3 の残り、3.4、3.5 は、同書の処理フロー図と本書で補い、不足は「未決」に記す。

## 1. 目的
教科書のテキスト(.txt / .md)を、ローカルの VOICEVOX Engine で章ごとの MP3 に変換する。外部へ送信せず、無料で、数万文字を一括で処理できる。

## 2. 範囲
**含む(MVP)**: テキスト入力、前処理(ルビ、図表参照、ページ表記、英数字と単位の読み)、章の分割、音声合成用のチャンク分割、VOICEVOX による合成、ポーズ付きの結合、ラウドネス均一化、MP3 化と ID3 タグ、コマンドライン。
**含まない(backlog)**: ユーザー辞書の CSV 同期(要求 3.1.3)、カバーアートの埋め込み、DirectML の対応、形態素解析による境界判定(接続詞・助詞の前での分割。MVP は文字種で近似する)、数字の日本語読みへの展開(MVP は VOICEVOX に任せる)、括弧の種別ごとのポーズ、図表参照符の導入文への置換、GUI、PDF の直接入力。

## 3. 機能要件
- **[REQ-2026-002-F01] 入力**: `.txt` と `.md` を読む。文字コードは UTF-8(BOM あり・なし)を標準とし、UTF-8 として読めなければ Shift_JIS(CP932)として読む。どちらでも読めなければ、ファイル名を示して失敗する。
- **[REQ-2026-002-F02] 前処理**: 次を、読み上げる文字列に変換する。(a) ルビ: 青空文庫形式 `漢字《かんじ》`、Markdown 形式 `[漢字](かんじ)`、`<ruby>漢字<rt>かんじ</rt></ruby>` を、読み(ふりがな)側だけにする。(b) ページ表記(`--- 124 ページ ---` の形)と区切り線を除く。(c) 図表の参照符(`図1-1`、`表2-3`、`[写真]`)を、設定の既定どおり、除く。(d) 英数字と単位記号を、読みの表で日本語の読みに展開する(`CO2`、`km/h`、`pH`)。3 桁区切りの数はカンマだけを除く(`1,000` → `1000`)。数字の読み(`せん`)は VOICEVOX に任せる。(e) Markdown の装飾記号(`#`、`*`、`` ` `` など)を読み上げない。
- **[REQ-2026-002-F03] 章の分割**: 見出し(Markdown の `#`/`##`、`第N章`、`第N節`、`1.1` の形の数字見出し)で章に分ける。見出しがなければ全体を 1 章とする。章ごとに 1 つの MP3 を作り、ファイル名は `NN_見出し.mp3`(`NN` は 2 桁以上の連番)とする。ファイル名に使えない文字は置き換える。
- **[REQ-2026-002-F04] チャンク分割**: 章の本文を、合成の 1 回分(既定は 80 文字以内)に分ける。優先順位は、段落(改行)、文末(`。` `！` `？`)、読点(`、`)、上限での強制分割。強制分割でも、同じ文字種(漢字、ひらがな、カタカナ、英数字)の連続の途中では切らない(上限の位置から手前へ戻り、文字種が変わる位置で切る)。連続が上限を超える場合に限り、上限で切る。元の要求の「接続詞や助詞の前」での分割は、形態素解析が要るので MVP では行わず、文字種による近似に置き換える。分けた文字列を連結すると元の文字列に戻る(文字を落とさない)。
- **[REQ-2026-002-F05] 音声合成**: VOICEVOX Engine の HTTP API で、`/audio_query` に文字列と話者 ID を渡し、得た問い合わせを `/synthesis` に渡して WAV を得る。話者 ID、話速、抑揚、音量、エンジンの URL は設定で与える。接続に失敗したときは、エンジンの URL を示して失敗する。一時的な失敗(接続の失敗、5xx)は、設定の回数まで再試行する。
- **[REQ-2026-002-F06] 結合とポーズ**: 章ごとに、チャンクの WAV を順に 1 つに結合する。チャンクの間に、直前の区切りの種類(段落、文末、読点、その他)に応じた長さの無音を入れる。長さは設定で与える。
- **[REQ-2026-002-F07] MP3 化**: 結合した音声を、FFmpeg でラウドネスを均一にして(EBU R128)、MP3 に変換する。ID3v2.4 のタグ(題名=見出し、アルバム=入力ファイル名、トラック番号=連番)を付ける。FFmpeg の実行ファイルは設定(`--ffmpeg`、既定は `ffmpeg`)で指定できる。見つからなければ、その旨を示して失敗する。出力先のディレクトリがなければ作る。
- **[REQ-2026-002-F08] コマンド**: `python -m src.txt2speech INPUT -o OUTDIR` で、F01〜F07 を実行する。進捗(章の番号、チャンクの数)を標準エラーに出し、作ったファイルの一覧を標準出力に出す。終了コードは、成功 0、入力・設定の誤り 2、エンジン・FFmpeg の失敗 3。

## 4. 非機能・前提
- 完全にローカルで動く。外部ネットワークへ送らない(VOICEVOX の URL は既定でループバック)。 [原典: 要求定義書 1.1]
- 長い入力でも、メモリに保持するのは 1 章分の音声(24 kHz、モノラル、16 ビットで 1 時間あたり約 170 MB)までとする。章を出力したら破棄する。
- 実機(GTX 1660 Super、VOICEVOX の GPU モード)での合成速度と音質は、自動テストの対象外(手動確認)。自動テストは、VOICEVOX を偽の HTTP サーバーに置き換える。
